# Manoj Teja Site Cleanup Checklist

This checklist protects the production Astro site from accidental deployment of stale build output, local audio files, temporary deploy folders, or unused generated assets.

## Current production rules

- GitHub repository: `ymtchow/manojteja`
- Production domain: `https://manojteja.com`
- Default branch: `main`
- Netlify should build from source, not from committed `dist/` output.
- No local audio files should be committed to the repository.
- Active article audio must remain externally hosted at Cloudflare R2:
  `https://pub-dfe7ff4631c440c1a5716662c3bfabb5.r2.dev/Podcast%20Whose%20law%20%3F%20which%20court%20%3F.m4a`

## Safe local cleanup order

1. Confirm the live site works:
   - `/`
   - `/articles/`
   - `/articles/whose-law-which-court/`
2. Confirm the active article audio plays from the Cloudflare R2 URL above.
3. Run a local build from a clean working tree:
   - `npm install`
   - `npm run build`
4. Delete local-only build output:
   - `dist/`
   - `.astro/`
   - `.netlify/`
5. Delete local-only temp deployment clones, including:
   - `/tmp/manojteja-deploy/`
6. Review generated image experiments before deletion.
7. Review local audio masters before deletion; keep archival masters outside the repo if needed.

## Never commit

- `dist/`
- `.astro/`
- `.netlify/`
- `node_modules/`
- local `.mp3`, `.m4a`, `.wav`, `.aiff`, or `.flac` files
- temporary deploy clones
- generated zip backups
- unreviewed generated image experiments

## Files/folders to review carefully before deleting

- `src/content/articles/`
- `public/assets/`
- `public/images/`
- any unpublished article drafts
- any manually edited final artwork
- any original podcast/audio master files stored outside the repo

## All-clear definition

The project is wrapped when:

- GitHub is the source of truth.
- Netlify builds successfully from `main`.
- `dist/` is disposable and regenerated by Astro.
- No production route depends on local files.
- No audio binaries are committed.
- Article audio uses the approved Cloudflare R2 URL.
- Draft articles are visible but not clickable.
- The live home page and article pages pass desktop and mobile checks.
